Oil life & reset procedures

Reset the maintenance data (U.S.A. only)

Before you start

  • After the required maintenance is performed according to the maintenance schedule, please reset the maintenance data.

Steps

  1. Vehicles without smart key system
  2. Set the engine switch to the “LOCK” position with the trip meter A reading shown. (→P. 185)
  3. While pressing the trip meter reset button, set the engine switch to the “ON” position.
  4. Vehicles with smart key system
  5. Set the “ENGINE START STOP” switch OFF with the trip meter A reading shown. (→P. 185)
  6. While pressing the trip meter reset button, set the “ENGINE START STOP” switch to the IGNITION ON mode.
  7. Without multi-information display: Continue to press and hold the button until the trip meter displays “000000”.
  8. With multi-information display: Continue to press and hold the but- ton until “COMPLETE” appears on the multi-information display.
  9. Maintenance and care

You’ll know it worked: Without multi-information display: Continue to press and hold the button until the trip meter displays “000000”.

Source: Toyota 2012 Highlander Owners Manual (OM48A09U), page 447
