Oil life & reset procedures

Engine oil life monitor reset

Steps

  1. Press and release the SETUP control to display “OIL LIFE = XXX% HOLD RESET = NEW”.
  2. Press and hold the RESET control for 2 seconds and release. Oil life is set to 100% and “OIL LIFE SET TO 100%” is displayed.
  3. While “OIL LIFE SET TO 100%” is displayed, if a lower oil life start value is desired, press and release the RESET control to reduce the start value. Each press of the RESET control reduces the value by 10 percent.

Source: Owner’s Manual Printing 3 (PDF), page 70
