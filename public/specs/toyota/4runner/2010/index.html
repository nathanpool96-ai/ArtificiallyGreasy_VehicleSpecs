Oil life & reset procedures

Reset the maintenance data (U.S.A. only)

Before you start

  • After the required maintenance is performed according to the maintenance schedule, please reset the maintenance data.

Steps

  1. Switch the display to the trip meter A (→P. 184) when the engine is running.
  2. Vehicles without a smart key system
  3. Turn the engine switch off.
  4. Vehicles with a smart key system
  5. Turn the “ENGINE START STOP” switch off.
  6. Vehicles without a smart key system
  7. While pressing the trip meter reset button (→P. 184), turn the engine switch to the “ON” position (do not start the engine because reset mode will be canceled). Continue to press and hold the button until the trip meter displays “000000”.
  8. Vehicles with a smart key system
  9. While pressing the trip meter reset button (→P. 184), turn the “ENGINE START STOP” switch to the IGNITION ON mode (do not start the engine because otherwise the reset mode will be can- celed). Continue to press and hold the button until the trip meter displays “000000”.
  10. Maintenance and care

You’ll know it worked: While pressing the trip meter reset button (→P. 184), turn the “ENGINE START STOP” switch to the IGNITION ON mode (do not start the engine because otherwise the reset mode will be can- celed). Continue to press and hold the button until the trip meter displays “000000”.

Source: Toyota 2010 4Runner Owners Manual (OM35A36U), page 485
