Oil life & reset procedures

Reset the maintenance data (U.S.A. only)

Before you start

  • After the required maintenance is preformed according to the maintenance schedule, please reset the maintenance data.

Steps

  1. Switch the display to the trip meter A when the engine is running. (→P. 177)
  2. Vehicles with smart key system: Turn the “ENGINE START STOP” switch off.
  3. Vehicles without smart key system: Turn the engine switch to the “LOCK” position.
  4. Vehicles with smart key system: While pressing the trip meter reset button, set the “ENGINE START STOP” switch to IGNITION ON mode (but do not start the engine because otherwise the reset mode will be canceled). Continue to press and hold the trip meter reset button until the trip meter dis- plays “000000”.
  5. Vehicles without smart key system: While pressing the trip meter reset button, set the engine switch to “ON” position (but do not start the engine because otherwise the reset mode will be canceled). Continue to press and hold the trip meter reset button until the trip meter displays “000000”.
  6. Maintenance and care

You’ll know it worked: Vehicles without smart key system: While pressing the trip meter reset button, set the engine switch to “ON” position (but do not start the engine because otherwise the reset mode will be canceled). Continue to press and hold the trip meter reset button until the trip meter displays “000000”.

Source: Toyota 2012 Venza Owners Manual (OM73013U), page 493
