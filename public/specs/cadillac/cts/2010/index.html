Oil life & reset procedures

Engine oil life system reset

Before you start

  • Reset the system whenever the engine oil is changed so that the system can calculate the next engine oil change.
  • with the engine off.

Steps

  1. Turn the ignition key to ON/RUN with the engine off.
  2. Fully press and release the accelerator pedal three times within ﬁve seconds. If the CHANGE ENGINE OIL SOON message is not on, the system is reset.

You’ll know it worked: If the CHANGE ENGINE OIL SOON message is not on, the system is reset.

Source: 2010 Cadillac CTS and CTS V Owner Manual, page 9-13
